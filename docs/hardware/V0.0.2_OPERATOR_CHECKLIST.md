# PocketOS v0.0.2: operator checklist for the first physical validation

Sequential. Stop at the first failed step and record it. Every command runs
as root on the device unless marked PC. Image and hashes:
`docs/hardware/V0.0.2_BUILD_REPORT.md`. Do not transmit at any step.

## PRE-FLASH

- [ ] The golden v0.0.1 card stays out of the reader and unwritten. Golden image
      `out\k230\sysimage-sdcard.img` = `bafed837…3ad6`; nothing else touches `out\k230`.
- [ ] PC: COM9 login works right now (PuTTY, 115200, root, no password) on the
      golden card. If not, fix serial first: v0.0.2 has no other way in.
- [ ] PC: v0.0.2 image ready, hash verified before writing:
      ```
      Get-FileHash C:\K230\out\k230-v0.0.2\sysimage-sdcard.img -Algorithm SHA256
      ```
      expect `A373BCCE3A175943862E1005452F55926FCBB4550581367D639F243F3AC26D0C`.
- [ ] Write to a **second** card (raw write, read-back compare); label it v0.0.2.
      Never the golden card.

## FIRST BOOT (serial console only, no network commands yet)

- [ ] v0.0.2 card in, power on, watch rcS on COM9. Expect
      `Starting radiod (mock, EU868, 2 dBm): OK`, `Starting telnetd: OK`,
      `Starting pocketos-shell: disabled (/etc/default/pocketos-shell)`; the
      vendor launcher owns the panel, as on a fresh v0.0.1 card.
- [ ] `cat /etc/pocketos-release` → `0.0.2`.
- [ ] `pos radio info` → backend `mock`, region `EU868`; `pos radio status` →
      `"tx_power_dbm": 2`, state `rx`.
- [ ] `netstat -tln | grep ':23 '` → `127.0.0.1:23` only (not `0.0.0.0:23`).
- [ ] Hand the panel to the shell, as on unit A:
      ```
      printf 'ENABLE=0\n' > /etc/default/k230_phone_ui
      printf 'ENABLE=1\n' > /etc/default/pocketos-shell
      /etc/init.d/S99zz_k230_phone_ui stop; killall -q k230_phone_ui
      /etc/init.d/S90pocketos-shell start
      ```
      Launcher appears on the panel; `pos shell info` answers; note
      `cat /run/pocketos/pocketos-shell.pid`.
- [ ] `ls /etc/default/radiod` → absent. Do NOT create it yet (sx1262 stays off).

## SECURITY

- [ ] `ip -4 addr show eth0` → note the IP (changes per boot, random MAC).
- [ ] PC: `ssh -o PubkeyAuthentication=no root@<ip>` with an empty password →
      `Permission denied`. Must NOT get a shell.
- [ ] PC: `Test-NetConnection <ip> -Port 23` → `TcpTestSucceeded : False`.
- [ ] Serial: `passwd` → set the root password (not recorded anywhere in the repo).
- [ ] PC: `ssh root@<ip>` with that password → shell. `cat /etc/pocketos-release` → `0.0.2`.
      From here SSH may be used; keep COM9 open.

## RADIO (no TX)

- [ ] `pos radio status` → `tx_power_dbm` 2 (mock).
- [ ] `pos radio configure tx_power_dbm=10`; `pos radio status` → 10.
      `/etc/init.d/S60radiod restart`; `pos radio status` → 2 again.
- [ ] Antennas confirmed on MMCX1 (the SX1262 port) and MMCX2 before the next step.
- [ ] `printf 'RADIOD_BACKEND=sx1262\n' > /etc/default/radiod`;
      `/etc/init.d/S60radiod restart` → line reads `(sx1262, EU868, 2 dBm): OK`.
- [ ] `pos radio info` → backend `sx1262`; `pos radio status` → state `rx`,
      `tx_power_dbm` 2. No `pos radio send`, no pair test, no CAD sweep.
- [ ] Ownership refusal: `pos-hwcheck --lora /root/hwcheck-v002` → exit code `3`
      (`echo $?`), text `REQUIRES RADIOD STOPPED`, inventory report still written.
- [ ] `/etc/init.d/S60radiod stop`; `pos-hwcheck --lora /root/hwcheck-v002` →
      exit `0`, `14 24`, `SX126x answers`. Finishes within 15 s.
- [ ] `ps | grep '[g]pioset'` → nothing.
- [ ] `/etc/init.d/S60radiod start` → `(sx1262, EU868, 2 dBm): OK`;
      `pos radio status` → `rx`, 2 dBm (radio initialises after the probe released the lines).

## SIGPIPE

- [ ] `cat /run/pocketos/pocketos-shell.pid` → note SHELL_PID. Shell on the panel.
- [ ] `kill -9 $(cat /run/pocketos/radiod.pid)`. Wait 3 s.
- [ ] `cat /run/pocketos/pocketos-shell.pid` → same SHELL_PID; `pos shell info`
      answers; the panel did not restart.
- [ ] `pos radio info` → answers with a new radiod pid; Radio app on the panel
      shows the service back. `tail -3 /var/lib/pocketos/log/supervise-radiod.log`
      → one `exited rc=137` line with a small run time in seconds.

## LOGGING / SUPERVISOR

- [ ] `kill -SEGV $(cat /run/pocketos/radiod.pid)`. Wait 3 s.
- [ ] `ls /var/lib/pocketos/log/crash-radiod-*` → newest name ends in
      `-<time>-<pid>.txt` where pid is the radiod pid you just killed.
- [ ] `tail -2 /var/lib/pocketos/log/supervise-radiod.log` → `exited rc=139 after
      Ns` with N the real seconds since the last start (no 1788807617-style value).
- [ ] `pos radio status` → `rx`, 2 dBm (sx1262 recovered at the start-up power).

## FINAL

- [ ] `reboot`. On COM9: `(sx1262, EU868, 2 dBm): OK`, shell takes the panel.
- [ ] PC: `ssh root@<new ip>` with the password → works (password persisted).
- [ ] `pos shell info` and `pos radio status` (`rx`, 2 dBm) healthy;
      `ls /run/pocketos/*.crashloop` → none.
- [ ] Only now: approve low-power TX validation (2 dBm, one packet, MMCX1
      antenna confirmed) as a separate, explicitly authorised step.

Record results in `docs/hardware/BRINGUP_SESSION_<date>.md`. Rollback at any
point: power off, golden card in, power on.
