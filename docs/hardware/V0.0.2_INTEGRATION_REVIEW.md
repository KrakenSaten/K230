## 4. Security changes

Finding F1 (root SSH with an empty password open to the LAN, telnetd on all
interfaces). Options weighed: A (disable SSH until a credential exists) is
a dead end on a headless bench; B (`PermitEmptyPasswords no`) keeps sshd
running, refuses the empty password, and starts working the moment the
operator runs `passwd` on the serial console; C (key-only root) needs a
key copied over serial before any remote use; D (Buildroot root password)
embeds a secret in every image. **Chosen: B, plus telnetd bound to
127.0.0.1** through Buildroot's own `/etc/default/telnet` hook. Both are
deterministic (applied by `apply_to_sdk.sh` to the vendor sshd_config and
verified there, and by a PocketOS overlay file), recovery-safe (the serial
getty is untouched, root still logs in locally without a password), and
embed nothing. Documented as "First login and remote access" in
`platforms/k230/README.md`, in `FIRST_BOOT.md` and in the checklist.
UNRESOLVED until a device runs the new image: that the vendor sshd honours
`PermitEmptyPasswords no` for an account with an empty shadow field (it
should; OpenSSH treats an empty password as empty) and that BusyBox telnetd
accepts `-b 127.0.0.1` on this build (documented option, not exercised).

## 5. Radio safety changes

- Start-up power is 2 dBm by default, or `--tx-power-dbm` from
  `/etc/default/radiod`; a restart can no longer raise the power above what
  the operator set at start. The profile is deliberately not persisted (a
  persisted raised power would defeat the point), documented in
  `docs/api/radio.md` and KNOWN_ISSUES.
- The start-up profile passes the same validation as `radio.configure`
  (chip range, LoRa bandwidth set, region guard), so a wrong
  `RADIOD_TX_POWER_DBM` stops radiod with exit 2 before `begin()`.
- Mock stays the default backend, EU868 the default region, sx1262 stays
  opt-in through `/etc/default/radiod`.
- The bench checklist's radio section carries the transmit precondition
  (antenna confirmed on the SX1262 port, MMCX1 on unit A) and the 2 dBm
  first send; `pos-hwcheck --lora` cannot run under an active sx1262 radiod.

## 13. Rollback strategy

- Card level: the golden v0.0.1 image (`bafed837…3ad6`) stays on its card
  and in `out/k230/`; a v0.0.2 card that misbehaves is swapped back, nothing
  on the board persists across cards.
- Configuration level on a v0.0.2 device: SSH access is restored by
  `passwd` on serial; the radio start power by `RADIOD_TX_POWER_DBM` in
  `/etc/default/radiod`; the panel by the existing launcher switch.
- Repository level: the branch is unmerged; master is `3d6120a`; each fix
  is its own commit and reverts independently; the two merges carry no
  conflicts.
