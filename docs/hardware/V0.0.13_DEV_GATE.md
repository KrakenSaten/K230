## Observations (not product defects)

- **MBR disk identifier on readback.** Windows writes a 4-byte disk
  identifier at offsets 440..443 when it sees an MBR whose signature is zero.
  The flash tool tolerates exactly that range; every other byte matched.
- **Serial command length.** The first factory-boot command sent over the
  console was longer than BusyBox's 1024-character line editor accepts and was
  cut, leaving the shell at a continuation prompt. It was cancelled with
  Ctrl-C and sent again in shorter pieces. Gate tooling, not the image.
- **Vendor Meshtastic probe at factory boot.** Until the panel is handed to
  Doors (`/etc/default/k230_phone_ui` `ENABLE=0`), the vendor launcher runs
  its own `k230_meshtastic_probe --daemon` (vendor behaviour). With the panel
  handed over, neither the launcher nor the probe runs.
- dmesg on every boot carries the same 9 boot-time vendor/driver probe lines
  (SPI IRQ index, aht10 absent, goodix config file, regulatory.db).
