# Doors 0.3.7 candidate: fresh-card hardware smoke test

**Build under test: `0.3.7`, `BUILD_ID=73ceadf5`** (release/v0.3.7 commit `73ceadf`). Check
it first: System > About, or `cat /etc/doors-release`.

Image: `C:\K230\out\doors-0.3.7-73ceadf\sysimage-sdcard.img`, 763,363,328
bytes, sha256 `a8941814bf90f5ecf2fe52a3cb19fa1c89e523c4436bc09c25c254cce5d98a24`. Compressed
release file `doors-0.3.7-tdisplay-k230-73ceadf5.img.gz`, sha256
`9505f57e7761249af30fe3a21698b904f7e58cf7a61f6d0266a8d334fdaa461e`.

What changes from v0.3.6 and is checked here: the first release image with
kernel patch 0075 (the board's own HDMI tree, so the kernel is rebuilt),
LVGL rebuilt with its QR facility (Help & Feedback), battery telemetry, the
RIFT basemap (off by default), DeskBuddy's Companion personality and the
game fixes. NinjaOne is not in this image.

**Coordinate every step with the owner. Nothing here is done without the
owner's go.** Use a spare card. The units' own cards are not touched.

## 1. Flash (PC, owner present)

A **spare** microSD card (16 GB or larger) as the only removable disk:

```powershell
powershell -ExecutionPolicy Bypass -File C:\K230\tools\flash-devcard.ps1 -Image C:\K230\out\doors-0.3.7-73ceadf\sysimage-sdcard.img -Sha256 a8941814bf90f5ecf2fe52a3cb19fa1c89e523c4436bc09c25c254cce5d98a24 -DryRun
```

If the dry run names the spare card, run it again without `-DryRun` and
record the `RESULT:` line.

Mark each PASS / FAIL with a note. Antenna on MMCX1 before any radio step.
