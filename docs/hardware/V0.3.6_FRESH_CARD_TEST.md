## 1. Flash (PC, owner present)

A **spare** microSD card (16 GB or larger) as the only removable disk:

```powershell
powershell -ExecutionPolicy Bypass -File C:\K230\tools\flash-devcard.ps1 -Image C:\K230\out\doors-0.3.6-9ad64a1\sysimage-sdcard.img -Sha256 76e05a5361477091b1edf29e54f4316aa8aa5d46f2a16eb5dcbfd09856e50da4 -DryRun
```

If the dry run names the spare card, run it again without `-DryRun` and
record the `RESULT:` line.
