## 1. Flash (PC, owner present)

Use a **spare** microSD card (16 GB or larger), not unit A's or unit B's own
card: the test needs a fresh card, and a unit's own card holds its identity.
Only that card may be in a USB reader; the tool refuses to choose between
two removable disks and never writes disk 0 or the system disk.

```powershell
powershell -ExecutionPolicy Bypass -File C:\K230\tools\flash-devcard.ps1 -Image C:\K230\out\doors-0.3.5-3d4ea6e\sysimage-sdcard.img -Sha256 40e8a8a05c3033a94e30330f8edadb3be29ccde4d943e73dfccfa7d379a6a3fc -DryRun
```

The dry run names the disk it would write. If that is the spare card:

```powershell
powershell -ExecutionPolicy Bypass -File C:\K230\tools\flash-devcard.ps1 -Image C:\K230\out\doors-0.3.5-3d4ea6e\sysimage-sdcard.img -Sha256 40e8a8a05c3033a94e30330f8edadb3be29ccde4d943e73dfccfa7d379a6a3fc
```

It asks for elevation (UAC), writes, reads back and ends with
`RESULT: FLASH PASS` (or `FLASH FAIL`). Record that line.
