not; with the app open, SIGSTOP on radiod froze the panel until SIGCONT.

- [ ] Open the **Radio** app on the panel and leave it open.
- [ ] `kill -STOP $(cat /run/pocketos/radiod.pid)`
- [ ] Watch for 30 s: the status-bar clock keeps advancing, the radio chip

## M7 — the hwcheck probe reads the chip

Unit A, v0.0.3: RST released instead of driven high, BUSY stayed active,
registers read `ff`. Antenna fitted on MMCX1 as before (nothing is sent).

- [ ] radiod on mock (the default) or stopped: `pos radio info | grep backend`
      → `mock`, or `/etc/init.d/S60radiod stop`.
- [ ] ```
      pos-hwcheck --lora /root/hwcheck-v004; echo "exit $?"; ps | grep '[g]pioset' || echo "no gpioset"
      ```
      In the LoRa section: `reset: GPIO5 driven low for 20 ms, then driven
      high and held`; `BUSY (GPIO19) inactive within N ms of reset` (record
      N); the register line ending `14 24`; a GetStatus byte pair (a valid
      status byte, `a2 22` or similar, not `ff ff`); `sync word registers
      read 14 24 ... (VERIFIED)`; `no gpioset process left behind`;
      `exit 0`; `no gpioset`.
- [ ] Then the radio must still come up under radiod:
      ```
      printf 'RADIOD_BACKEND=sx1262\n' > /etc/default/radiod; /etc/init.d/S60radiod restart; sleep 3
      pos radio status | grep -E 'state|tx_power'; pos radio rssi
      ```
      `(sx1262, EU868, 2 dBm): OK`, state `rx`, `tx_power_dbm` 2, RSSI a
      plausible noise floor (about -90 to -110 dBm).
- [ ] Back to mock: `rm -f /etc/default/radiod; /etc/init.d/S60radiod restart`
      → `(mock, EU868, 2 dBm): OK`.
