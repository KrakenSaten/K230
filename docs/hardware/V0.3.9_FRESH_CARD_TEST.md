# Doors 0.3.9 candidate: fresh-card hardware smoke test

**Build under test: `0.3.9`, `BUILD_ID=c03795ce`** (release/v0.3.9 commit
`c03795ce`), the candidate image itself, on unit A with its own card taken
out and kept (that card holds the integration build and every rollback
folder; it was not written or modified).

Image: `sysimage-sdcard.img`, 763,363,328 bytes, sha256
`75b3f1aa7cd43b841d1dfa103d830a99047da41f4c68e0f60693012974876d31`
(WSL `~/work/rel-0.3.9/out/k230/`, copied to
`C:\k230\out\doors-0.3.9-c03795c\`).

A bounded smoke test: the image boots and carries what was integrated.
Feature acceptance (gameplay, detector accuracy, Guard, RF) rests on each
PR's own record and was not repeated. **No radio transmission was
authorised or configured.**

## 1. Flash, 2026-10-28

- **Target:** disk 1, "Mass Storage Device", USB, removable, reader serial
  `121220160204`, 15,634,268,160 bytes, not boot or system - the v0.3.6 to
  v0.3.8 spare reader. Listed read-only and authorised by the owner; disk 0
  (the PC's NVMe system disk) was never a target.
- **Tool:** `C:\k230\out\v0.3.8-release\flash-card.ps1` (checks disk number,
  serial, USB, size, not boot/system; source hash gate; locks and dismounts
  the card's volumes; unbuffered read-back). A dry run passed first. A run
  from this session was refused before anything was written (`Set-Disk`:
  Access Denied, not elevated; the card's partitions were unchanged
  afterwards); the owner approved an elevated run.
- **Result:** source gate PASS (`75b3f1aa...6d31`); 763,363,328 bytes in
  61.7 s; **read back identical; `RESULT: FLASH PASS`** (log
  `C:\k230\out\doors-0.3.9-c03795c\flash-card-20261028-183948.log`). The
  card was ejected through the shell before removal.
