# Doors v0.0.12 RC1: unit A gate, 2026-09-24

**Status: RC1 built and gated on unit A as a DEPLOY, not as a flashed card.**
Nobody flashed the image. No SD reader or card was attached to the build host
during the run, which was unattended, and moving the card is a physical step
for the owner. Everything below ran on the RC1 userspace deployed over SSH
onto unit A's existing card. The boot partition and kernel on that card are
v0.0.11 RC1's. RC1's boot partition carries the same `Image` and device trees
(the build log's `Carried` line); nothing was compared on the card.

**Unit A carries RC1 `a8b1a9f`** (0.0.12), deployed with
`platforms/k230/scripts/deploy.sh` from the RC1 build's target tree. All 37
deployed files hashed the same on the unit as in that tree, and
`/etc/doors-release`, `doors version`, radiod and meshcored all say
`a8b1a9f`. The unit was left at home, portrait (rotation stored:
portrait), unlocked, with meshcored online. Rollback to what the unit ran
before the fullscreen gate: `sh /root/rollback-fullscreen/RESTORE.sh` (RC1
`9a4afeb` userspace with the Files shell `2bccc5b`).
