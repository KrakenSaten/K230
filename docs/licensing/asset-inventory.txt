# licence (docs/licensing/B1_ARTWORK.md; APACHE_2_READINESS.md §6).
# tests/license_audit_test.sh fails when a tracked asset matches no rule,
# when a rule matches nothing, or when a class is not one of those below.
#
# Format: <pattern> <CLASS> <note>. Patterns are shell globs over the
# repository path (* also crosses /); the FIRST rule that matches decides.
#
# Classes, and the licence each carries:
#   ORIGINAL          made in this repository (drawn, or generated from
#                     original inputs), or a capture that predates the owner's
#                     ChatGPT art. Apache-2.0
#   OWNER-VECTOR      vector art the owner made with ChatGPT (owner,
#                     2026-10-02). Apache-2.0
#   OWNER-AI-RASTER   images the owner made with an AI tool: ChatGPT's image
#                     generation (OpenAI content credentials) or Claude
#                     (Anthropic content credentials). Apache-2.0, to the
#                     extent rights subsist in them
#   OWNER-DESIGN      design source document the owner made with an AI tool
#                     (Claude). Apache-2.0
#   BRAND             the Doors mark, lockups and boot art, made by the owner
#                     with ChatGPT. Reserved: docs/licensing/BRAND.md
#   DERIVED-ART       generated in this repository from ORIGINAL and OWNER-*
#                     art. Apache-2.0
#   DERIVED-BRAND     generated here from BRAND art. Reserved: BRAND.md
#   CAPTURE           capture of Doors changed on or after 2026-09-15 09:09
#                     (+02:00); Apache-2.0, and any Doors mark it shows keeps
#                     the BRAND.md terms
#   OWNER-REF         reference-only parts of the owner's packages (mockups,
#                     style sheet, overviews, archive copies); excluded from
#                     the public source
#   DESIGN-EXPORT     design-tool export with no stated terms; excluded (B2)
#   THIRD-PARTY       someone else's material under its own licence; excluded
#                     from the public source unless that licence allows
#                     redistribution and its notice ships
