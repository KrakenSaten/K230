# Every tracked artwork, image and design asset, classified for the
# Apache-2.0 source release (docs/licensing/APACHE_2_READINESS.md §6, B1).
# tests/license_audit_test.sh fails when a tracked asset matches no rule,
# when a rule matches nothing, or when a class is not one of those below.
#
# Format: <pattern> <CLASS> <note>. Patterns are shell globs over the
# repository path (* also crosses /); the FIRST rule that matches decides.
#
# Classes:
#   ORIGINAL          made in this repository: drawn here, generated here from
#                     original inputs, or a capture that predates any B1 art
#   CAPTURE-B1        capture of Doors changed on or after 2026-09-15 09:09
#                     (+02:00), when the first B1 art entered the tree; it may
#                     show B1 art and follows B1's answer
#   SUPPLIED-VECTOR   owner-supplied vector artwork; author and terms not stated
#   SUPPLIED-BRAND    owner-supplied brand marks, lockups and boot art; author
#                     and terms not stated
#   AI-RASTER         AI-generated raster image (OpenAI content credentials,
#                     or resized from one, per the supplier's PROVENANCE.md)
#   DERIVED-B1        generated in this repository from supplied or AI art;
#                     follows its inputs
#   DERIVED-BRAND     generated here from supplied brand art; follows it
#   SUPPLIED-REF      supplier mockups, references, overviews and archive
#                     copies; reference only, excluded from the public source
#   DESIGN-EXPORT     design-tool export; excluded from the public source (B2)
#   THIRD-PARTY       someone else's material under its own licence
