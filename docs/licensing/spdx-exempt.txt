# each with the reason (docs/licensing/APACHE_2_READINESS.md §2, "Source

# that has neither the line nor an entry here, on an entry for a file that is
# no longer tracked, and on an entry without a reason.
#
# Format: <path> <reason>. Reasons:
#   MIXED        the file says "Apache-2.0 AND <licence>": it adapts code under
#                that licence, named in its header
#   NOT-CLEARED  holds material whose licence is not established; not offered
#                under Apache-2.0 until it is
#   GENERATED    generated; its licence follows its inputs (the generator is
#                tagged)
#   PENDING      first-party, covered by LICENSE, written before the header
#                rule; the header is a follow-up (no behaviour change here)
