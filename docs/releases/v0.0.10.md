# Doors 0.0.10 release notes

Doors 0.0.10 is the first release under the Doors name, for the LILYGO
T-Display K230. The platform was called PocketOS through v0.0.9
(docs/decisions/ADR-005-product-name-doors.md).

Release candidate: the build, image checksums, test counts and the unit A
hardware gate are in docs/hardware/V0.0.10_RELEASE_SMOKE.md.

Doors' own licence is not decided. No licence is granted and redistribution of
Doors, as source or as an image, is not authorised (docs/LICENSING.md).

## What changed since v0.0.9

### Doors on screen

- The product is Doors wherever a user reads the name: `DOORS` in the status
  bar, the System app's identity row (`Doors  0.0.10 · <build>`), the Restart
  and Power off dialogs, and crash reports.
- The Threshold brand: a Doors boot splash from power-on, and the Doors mark
  before the name in System, tinted to match the theme.
- New launcher icons for all eleven apps, tinted with the theme's accent.

### Display

- **Rounded corners.** The status bar keeps its content clear of the panel's
  rounded corners: `DOORS` and the clock are no longer cut.
- **Rotation: Settings > Display > Rotation** offers Automatic, Portrait and
  Landscape. Portrait and Landscape are forced whatever is attached.
  Automatic is Landscape when the keyboard base is detected and Portrait when
  it is absent or cannot be read. Landscape is a quarter turn clockwise, as
  the vendor launcher uses with its keyboard, with a six-by-two launcher.
- **Touch follows the display** in every orientation.
- A change is applied by Doors itself: the screen goes dark for about a second
  while the shell restarts in place, any open app is closed, and the launcher
  comes back. The device is not rebooted. The choice is remembered.

### Also new since v0.0.9

- **Settings**, a new app: Wi-Fi, display brightness and rotation, and
  appearance (theme and display mode).
- **Wi-Fi** through the new network service: scan, join WPA and WPA2
  personal networks (a WPA2/WPA3 transition network joins as WPA2), open
  networks after a warning, saved networks rejoined at boot, Forget. Also
  `doors wifi` on the command line, including hidden networks. Saved
  passphrases are protected by file permissions only (root, 0600), not
  encrypted (ADR-003).
- **Display brightness**, remembered across reboots, with a 10 % floor.
- **Calculator**, a new app: the four operations with ordinary precedence, by
  touch or keyboard.
- **Wave**, a new app: short text messages (up to 64 bytes) sent and received
  as sound through the built-in speaker and microphone.
- The third-party notices ship in the image, in
  `/usr/share/doors/THIRD_PARTY_NOTICES.txt`.

### For operators

- **Commands.** The command-line tool is `doors` (`doors version` prints
  `Doors 0.0.10 (build <id>)`). `pos` stays a permanent alias and prints
  exactly what it printed before, so existing scripts keep working.
- **Release file.** `/etc/doors-release`; `/etc/pocketos-release` is a link
  to it and reads the same.
- **Shell service.** The shell is `/usr/bin/doors-shell`, started by
  `/etc/init.d/S90doors-shell` and configured in `/etc/default/doors-shell`.
  A unit that still has only `/etc/default/pocketos-shell` keeps its
  settings: that file is read, whole, when the new one does not exist. There
  is never a second shell: the service refuses to start beside a
  PocketOS-era shell, and no `pocketos-shell` service or binary remains.
- **Image.** `doors-0.0.10-tdisplay-k230-<build_id>.img.gz` with a `.sha256`
  file beside it. It decompresses to the same bytes as the build's
  `sysimage-sdcard.img`; flashing either writes the same card.
- **Unchanged on purpose.** `/var/lib/pocketos` (Wi-Fi, notes, saves, logs),
  `/etc/pocketos`, `/run/pocketos`, the `POCKETOS_*` variables and the
  `pos-*` helpers keep their names.

## Upgrading from v0.0.9

- **Recommended: flash the image.** A flash replaces the whole card. Notes,
  game saves, logs and any unit settings are not kept, and the SSH host key
  and `/root/.ssh/authorized_keys` are new, so set a password or key again on
  the serial console.
- **First boot shows the vendor launcher, as before.** To hand the panel to
  Doors, on the serial console or over SSH:

  ```sh
  echo ENABLE=0 > /etc/default/k230_phone_ui
  echo ENABLE=1 > /etc/default/doors-shell
  reboot
  ```

  Back to the vendor launcher: the same two files with the values swapped,
  then `reboot` (platforms/k230/README.md).
- **Bench update without a flash** (`platforms/k230/scripts/deploy.sh`) keeps
  `/var/lib/pocketos`, stops and removes the PocketOS-era shell service, and
  proves one shell remains. It does not write the boot partition, so the
  splash changes only with a flash.

## Rolling back

- **To v0.0.9: flash the v0.0.9 image** (tag `v0.0.9`). This is the supported
  way back.
- On the bench, the Doors names can be taken off a unit in the two steps
  ADR-005 records, each verified on unit A: `rollback_phase3.sh` removes the
  `doors-shell` service so an older `deploy.sh` can install
  `pocketos-shell` again, and after an older deploy
  `rm -rf /usr/bin/doors /etc/doors-release /usr/share/doors` removes the
  Doors-only files. That path has not been run end to end back to v0.0.9,
  and it leaves behind what v0.0.9 never had, such as the network service.

## Known limitations

- **Keyboard base: attach and remove it only with the board powered off and
  USB power removed.** The connector is not documented or electrically
  verified as safe to mate while powered. Attaching or removing it on a
  running unit has been seen to work, and Automatic rotation followed it, but
  that is not a supported operation.
- **No splash after a warm `reboot`.** The splash shows from power-on; after
  `reboot` the vendor U-Boot leaves the panel dark until Doors starts (about
  17 s). The unit boots normally.
- **Landscape covers the status bar and the launcher.** App screens keep their
  portrait width in landscape and scroll vertically; the touch keyboard stays
  568 px wide.
- **The corner inset (30 px) is provisional.** The touch keyboard's bottom
  row and the full-screen alert's corners still reach into the rounded
  corners.
- **Time is UTC**, in the clock, the status bar and alarms: the image has no
  time zone setting. There is no real-time clock, so the date is 1970 until
  the network time arrives.
- **Wi-Fi:** WPA3-only networks cannot be joined, passphrases must be
  printable ASCII, hidden networks can be joined only with `doors wifi`, and
  no regulatory domain is set.
- **Ethernet** over the USB adapter gets a new MAC address, and so possibly a
  new IP address, on every boot.
- **Wave:** range and speaker response are unmeasured; longer messages from
  other ggwave programs are heard but not shown.

The full list is docs/KNOWN_ISSUES.md.
